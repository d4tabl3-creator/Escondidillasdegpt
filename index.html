Cómo usar un atajo

Escribe el alias seguido de tu tarea. Para que sea fiable, añade una instrucción que explique el resultado, el formato, los límites y cómo comprobarlo. Puedes copiar solo el código o una instrucción lista para pegar desde cada ficha.

/mind-map
Tema: modelo de ingresos de un negocio digital.
Crea un mapa con concepto central, ramas, subramas,
relaciones, dependencias y riesgos. No inventes datos.
Entrega también una versión textual jerárquica.

Prueba de funcionamiento: si la interfaz muestra un menú de comandos al escribir /, el elemento pertenece a su lista nativa. Si no aparece, el texto puede seguir funcionando como instrucción, pero no como comando de interfaz.

No hay coincidencias. Prueba otra palabra o limpia los filtros.

Comandos de interfaz: no confundir entornos

La referencia consultada de slash commands describe una lista para la aplicación de escritorio y entornos de desarrollo. Incluye comandos como /plan, /goal, /model, /reasoning, /status, /archive, /rename, /review, /mcp, /worktree y otros. La propia referencia advierte que la disponibilidad depende del entorno y el acceso. No des por hecho que esa lista aparece en la app móvil estándar.

En ChatGPT también existen capacidades de producto como búsqueda web, investigación profunda, análisis de datos, carga de archivos, imágenes, voz, memoria, proyectos y tareas programadas, sujetas a disponibilidad y configuración. Se solicitan por la interfaz o describiendo la tarea; no necesitan inventar un slash code.

Fuentes y criterios

  1. Referencia de slash commands de ChatGPT Learn: comandos de interfaz y condiciones de disponibilidad.
  2. OpenAI Help Center: descripción de capacidades de ChatGPT: herramientas y funciones de producto.
  3. Wikiprompt: recopilación de atajos: etiquetas comunitarias de escritura, análisis y productividad.
  4. GitHub: ChatGPT Command Library: catálogo comunitario de códigos visuales, análisis y flujos.
  5. Shortblogging: Cheat Codes Library: ejemplos de atajos comunitarios y advertencia de que no son comandos oficiales.
  6. Bill Layne: 610 prompt shortcuts: recopilación amplia de etiquetas de comunidad; no equivale a 610 funciones nativas.
  7. Interactive prompt cheat sheet: referencia de patrones de prompts y distinción entre atajos y capacidades de interfaz.

Criterio editorial: se consolidaron variantes ortográficas y se marcaron usos ambiguos. Las descripciones explican la intención que suele asociarse a cada etiqueta; no certifican que exista un parser especial detrás de ella. Los nombres de estilo visual describen resultados solicitados, no algoritmos internos ni controles ocultos.
